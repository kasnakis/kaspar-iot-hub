# Συνεισφορά / Contributing

## Ελληνικά
- Ερωτήσεις και ιδέες: [Discussions](https://github.com/kasnakis/kaspar-iot-hub/discussions).
- Σφάλματα στο firmware ή στους οδηγούς: Issues, με πλακέτα, έκδοση core/βιβλιοθηκών και έξοδο Serial (χωρίς μυστικά).
- Pull requests: μικρές, στοχευμένες αλλαγές. Το CI κάνει compile τα sketches σε κάθε αλλαγή στο `firmware/`.
- Μην προσθέτετε ποτέ πραγματικά credentials στα `config.h` / `ca_cert.h`.

## English
- Questions and ideas: [Discussions](https://github.com/kasnakis/kaspar-iot-hub/discussions).
- Firmware or guide bugs: Issues, including board, core/library versions and serial output (without secrets).
- Pull requests: small, focused changes. CI compiles the sketches on every change under `firmware/`.
- Never add real credentials to `config.h` / `ca_cert.h`.
