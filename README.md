## Ελληνικά

Δημόσιο repository υποστήριξης της πλατφόρμας **KasPar-IoT**, μιας πλατφόρμας IoT πολλών οργανισμών για περιβαλλοντική, υδρολογική, μετεωρολογική, γεωτεχνική και βιομηχανική τηλεμετρία.

Εδώ θα βρείτε οδηγούς, firmware δοκιμών, decoders, βοηθητικά εργαλεία και υλικό παρουσίασης. **Ο πηγαίος κώδικας της πλατφόρμας δεν περιλαμβάνεται.**

| Φάκελος | Περιεχόμενο |
|---|---|
| [`index.html`](index.html) | Η σελίδα παρουσίασης (GitHub Pages), δίγλωσση |
| [`firmware/KasparIoT_Universal_ESP32`](firmware/KasparIoT_Universal_ESP32) | ESP32 MQTT client με TLS/mTLS και ρύθμιση από μενού Serial |
| [`firmware/KasparIoT_Universal_MKR1310`](firmware/KasparIoT_Universal_MKR1310) | LoRaWAN client για Arduino MKR WAN 1310 + decoder ChirpStack v4 |
| [`guides`](guides) | Οδηγοί σύνδεσης και εγκατάστασης |
| [`tools`](tools) | Βοηθητικά εργαλεία |
| [`marketing`](marketing) | Infographics και υλικό παρουσίασης |
| [`assets`](assets) | Λογότυπα και εικονίδια |

> ⚠️ Τα firmware είναι **πειραματικές εκδόσεις** για δοκιμές. Μην χρησιμοποιείτε παραγωγικά κλειδιά ή κωδικούς σε κοινόχρηστες πλακέτες.

## English

Public companion repository for **KasPar-IoT**, a multi-tenant IoT platform for environmental, hydrological, meteorological, geotechnical and industrial telemetry.

It holds guides, test firmware, decoders, helper tools and presentation material. **The platform's source code is not included.**

| Folder | Contents |
|---|---|
| [`index.html`](index.html) | Bilingual showcase page (GitHub Pages) |
| [`firmware/KasparIoT_Universal_ESP32`](firmware/KasparIoT_Universal_ESP32) | ESP32 MQTT client with TLS/mTLS and serial-menu configuration |
| [`firmware/KasparIoT_Universal_MKR1310`](firmware/KasparIoT_Universal_MKR1310) | LoRaWAN client for the Arduino MKR WAN 1310 + ChirpStack v4 decoder |
| [`guides`](guides) | Connection and installation guides |
| [`tools`](tools) | Helper tools |
| [`marketing`](marketing) | Infographics and presentation material |
| [`assets`](assets) | Logos and icons |

> ⚠️ The firmware is **experimental** and meant for testing. Do not use production keys or passwords on shared boards. Firmware guides are currently in Greek.
