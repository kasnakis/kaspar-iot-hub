# Ασφάλεια / Security

## Ελληνικά
Αν εντοπίσετε ευπάθεια στην πλατφόρμα KasPar-IoT ή στο firmware αυτού του repository, **μην ανοίξετε δημόσιο issue**. Χρησιμοποιήστε το [Private vulnerability reporting](https://github.com/kasnakis/kaspar-iot-hub/security/advisories/new) του GitHub.

Μην δημοσιεύετε ποτέ σε issues ή discussions tokens συσκευών, κωδικούς, ιδιωτικά κλειδιά, AppKeys ή διευθύνσεις παραγωγικών εγκαταστάσεων.

## English
If you find a vulnerability in the KasPar-IoT platform or in the firmware of this repository, **do not open a public issue**. Please use GitHub's [private vulnerability reporting](https://github.com/kasnakis/kaspar-iot-hub/security/advisories/new).

Never post device tokens, passwords, private keys, AppKeys or production hostnames in issues or discussions.
